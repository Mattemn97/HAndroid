HAndroid

Android 7+ · arm64 · senza root · versione di prova

Home Assistant su un vecchio telefono

HAndroid è un'app che contiene Home Assistant Core e il suo Python 3.14. La installi su un telefono che non usi più, la lasci in carica, e diventa il server della tua casa: sempre acceso, con Wi-Fi, Bluetooth e USB a portata di mano, senza Raspberry Pi e senza root.

Rilasci Indice dei pacchetti

Home Assistant vero

Lo stesso Home Assistant Core di un Raspberry, non una versione ridotta: interfaccia, automazioni, backup e integrazioni.

Sempre acceso

Riparte da solo dopo un crash, un riavvio del telefono o un aggiornamento, e tiene il Wi-Fi attivo a schermo spento.

Indice dei pacchetti Android

Alcune integrazioni di Home Assistant usano librerie con codice nativo che PyPI non pubblica per Android. Le compiliamo noi per arm64 e Python 3.14; l'app le scarica da qui quando aggiungi l'integrazione. Per pip l'indice è wheels/.
